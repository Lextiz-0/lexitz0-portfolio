03 / despliegue continuo

Se actualiza solo

Este sitio se compila y publica con GitHub Actions cada vez que se sube un archivo al repositorio. Sin pasos manuales.

  1. 1

    Subes un archivo

    Un proyecto nuevo en projects/, una imagen en assets/ o un cambio de diseño.

  2. 2

    Se detecta el cambio

    El flujo identifica qué archivos son nuevos o cambiaron y los registra en el resumen.

  3. 3

    Se valida y compila

    Revisa que cada proyecto tenga los campos necesarios y genera la versión final del sitio.

  4. 4

    Se publica

    GitHub Pages sirve la nueva versión en uno o dos minutos.
